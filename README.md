# Employee Management System

A full-stack Employee Management System built with Java Spring Boot, React, and MySQL for the Kinetrexa Internship Task Assignment.

## Features
- User Authentication & Authorization
- Employee CRUD Operations
- Department & Role Management
- Attendance & Salary Management
- Search & Filter Functionality

## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA, REST API
- **Frontend:** React, Axios, CSS
- **Database:** MySQL

## Database Setup
1. Create database: `employee_db`
2. Run the `schema.sql` script located in the project root.

## How to Run

### Backend (Spring Boot)
1. Open the `/backend` directory in your IDE.
2. Update `application.properties` with your MySQL credentials.
3. Run `mvn spring-boot:run`.

### Frontend (React)
1. Navigate to `/frontend`.
2. Run `npm install`.
3. Run `npm run dev`.
